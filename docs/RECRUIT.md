## 版本一 · 群公告（简洁版）

【吉利 ICON 2020 款 E01 车机 · CarPlay 适配共建】

我们开了一个开源仓库，专门做 ICON / E01 车机的 CarPlay 适配。

**现状**：官方 DiPlay 要求安卓 9 以上，我们的 E01 是安卓 5.1，装不上；社区的低版本分支目前只验证过比亚迪车机，吉利这边是空白。

**现在最缺的不是程序员，是数据。**

只要你在车上拍一张「设置 → 关于本机」的照片，把下面几项填给我们就行：

- 系统版本（那串完整数字，最重要）
- 安卓版本
- 硬件版本 / MCU 版本
- 屏幕分辨率
- 能否安装第三方 APK

提交地址：https://github.com/Brunooooooooooooooo/diplay-geely-e01-5.1/issues/new?template=census.yml

**注意**：提交前请删掉蓝牙 MAC、车架号、热点密码这些个人信息。

已有台架车机在测，跑出结果会同步到仓库。

## 版本二 · 论坛长帖（详细版）

**标题建议**：吉利 ICON 2020 款 E01 车机 CarPlay 适配 —— 开源共建，求固件样本

### 为什么要单开一个项目

现在市面上三个 DiPlay 相关项目，没有一个覆盖我们这台车：

| 项目 | 覆盖范围 | 和 E01 的关系 |
|---|---|---|
| DiPlay 官方版 | 比亚迪 DiLink，安卓 9+ | 我们 5.1，装不上 |
| DiPlay Legacy 分支 | 安卓 4.4+ | 理论上能装，但没做过任何非比亚迪车机验证 |
| 吉利 4.3 适配版 | 博瑞 H52，安卓 4.3 | 版本对不上，固件桥接不适用 |

所以 E01 + 安卓 5.1 这一格是空的。

### 关于批次（这条很重要）

ICON 2020 款分两批：**2020 年 6 月前生产的多是安卓 4.3，之后是 5.1**。
本仓库主线做 5.1；如果你是 4.3，请去 xikai6282 的吉利 4.3 仓库，也欢迎在普查表里注明，帮我们摸清批次分布。

### 现在需要你做什么

**第一步（最重要）：报固件信息**

车上「设置 → 关于本机」，拍张照，把这几项提交上来：

- 系统版本完整串（形如 09.02.10300.H10.00002）
- 安卓版本
- 硬件版本、MCU 版本
- 屏幕分辨率
- 能否装第三方 APK、用的什么方式装的
- iPhone 机型 + 精确 iOS 版本

提交入口：https://github.com/Brunooooooooooooooo/diplay-geely-e01-5.1/issues/new?template=census.yml

会 ADB 的可以直接跑：

```bash
adb shell getprop ro.build.display.id
adb shell getprop ro.build.version.release
adb shell wm size
```

**第二步（有能力的车友）：跑一遍测试清单**

仓库里有完整的测试清单（docs/TESTING.md），按项打勾就行。**失败的结果同样重要**，请写清楚卡在哪一步：装不上 / 启动闪退 / 搜不到手机 / 握手失败 / 出画面没声音 / 触控没反应。

### 关于安装包

仓库**不分发任何现成的可用安装包**，也不放认证相关的文件。原因写在 README 里了。后面会提供本地重打包脚本的思路，用官方渠道的包在自己电脑上组装。

### 风险提示

- 这不是苹果认证产品，依赖社区提取的实验性配件身份，iOS 大版本更新后可能失效
- 车机装第三方 APK 可能影响原厂功能、OTA 和质保
- 所有操作请在驻车状态下做，改之前自己备份

### 能不能成

不好说。但空白不是靠抱怨填上的。先把固件分支摸清楚，至少能让后面想动手的人知道从哪开始。
