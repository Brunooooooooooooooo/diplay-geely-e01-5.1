## 怎么取这些信息

在车机上：**设置 → 关于本机**（部分车机叫「关于设备」/「系统信息」），逐行抄下来，建议直接拍照。

| 字段 | 位置 | 为什么重要 |
|---|---|---|
| 系统版本 | 关于本机 | **最关键**。形如 `09.02.10300.H10.00002`，是判断固件分支的唯一可靠依据 |
| 安卓版本 | 关于本机 | 确认 4.3 还是 5.1，决定走哪条主线 |
| 硬件版本 | 关于本机 | 区分硬件批次（早期批次被车主投诉为非 E01 芯片） |
| MCU 版本 | 关于本机 | 影响方向盘按键与音量控制的映射 |
| 屏幕分辨率 | 设置 → 显示，或用 ADB `wm size` | 决定解码负载与画面适配参数 |

ADB 方式（车机已开启调试时更准）：

```bash
adb shell getprop ro.build.display.id      # 系统版本
adb shell getprop ro.build.version.release # Android 版本
adb shell getprop ro.product.board         # 硬件平台
adb shell wm size                          # 屏幕分辨率
adb shell wm density
```
