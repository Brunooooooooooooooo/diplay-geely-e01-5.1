## 已知限制（继承自上游，非 E01 专属）

- 偶发音频断续，上游已推迟到后续版本修复
- 高视频负载下车机可能卡顿 → 建议先 **30 fps、关闭 HEVC、适当降低分辨率**
- 自动启动取决于车机固件与自启动权限
- 通话、Siri、后台重连、长途场景需要更广泛测试
- 支持加入 5 GHz 网络的车机，仍可能拒绝 5 GHz Wi-Fi Direct 组

## E01 专属待验证项

- [ ] 原厂蓝牙通路能否用于 CarPlay 配对
- [ ] 方向盘按键（切歌 / 音量 / 长按 Siri）映射
- [ ] 倒车影像 / 360 环视切换后画面与声音是否恢复
- [ ] 熄火重启后是否需要手动重连
- [ ] 首次启动的权限引导流程
- [ ] 车机热点频段实际能力（2.4G 还是 5G）
