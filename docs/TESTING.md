## 日志与诊断报告

应用内导出：**设置 → 诊断 → 保存诊断报告**
Android 10+ 通常保存到 `Downloads/DiPlay`；Android 9 及以下走文件选择器；均不可用时用确认框的「查看 / 分享」。

logcat（需 ADB）：

```bash
adb logcat -v threadtime -s DiPlay:* *:E > diplay-$(date +%Y%m%d-%H%M).log
```

复现问题后立即停止抓取，并**记下故障发生的精确时间**。
